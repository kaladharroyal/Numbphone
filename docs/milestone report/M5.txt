1. OBJECTIVES & DELIVERABLES ACHIEVED
--------------------------------------------------------------------------------
- Centralized Launch Decision Engine:
  * Implemented pure-domain evaluation in `com.minimalphone.core.domain.launch.EvaluateAppLaunchUseCase`
  * Rule 1: Always Available (Essential) apps are never blocked under any state or mode.
  * Rule 2: Inactive focus session allows launching of any managed app.
  * Rule 3: Active focus session in STRICT or DEEP_FOCUS mode returns `AppLaunchDecision.Block`.
  * Rule 4: Active focus session in LIGHT mode returns `AppLaunchDecision.ShowFriction` with countdown.
- Launch Interception & Blocked Attempt Logging:
  * `LaunchAppUseCase` intercepts package launch intent, queries `EvaluateAppLaunchUseCase`, and records `BlockedAttempt` in Room when blocked.
  * `DefaultBlockedAttemptRepository` records attempts with timestamp, app label, route ("LAUNCHER"), and active focusSessionId.
- Blocked Attempt UI & Dialog:
  * Created `BlockedAppDialog` in `core:ui` styled with pure monochrome design (`MinimalTheme`).
  * Displays active focus goal (e.g., "DBMS Revision"), custom blocking message, and an "Understood" dismiss action.
- Home Screen Integration:
  * Updated `HomeViewModel` to trigger `LaunchAppUseCase` on app selection.
  * Connected `HomeScreen` to display `BlockedAppDialog` on `AppLaunchDecision.Block` or trigger intent launch on `AppLaunchDecision.Allow`.
